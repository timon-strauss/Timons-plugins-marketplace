# Timons Plugins Marketplace

A Claude Code plugin marketplace collecting my personal plugins.

## Installation

In Claude Code:

```
/plugin marketplace add timon-strauss/Timons-plugins-marketplace
```

Then install individual plugins:

```
/plugin install paper-maker@Timons-plugins-marketplace
/plugin install notification-plugin@Timons-plugins-marketplace
```

## Plugins

- **paper-maker** — AI assistant that guides SAP dual students through writing academic papers. Source: [paper-maker-plugin](https://github.com/timon-strauss/paper-maker-plugin)
- **notification-plugin** — Focus-aware macOS notifications for Claude Code. Source: [notification-plugin](https://github.com/timon-strauss/notification-plugin)
